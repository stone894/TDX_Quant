# 个股历史PE/PB

**可以计算。**  

建议把三类数据按日期拼接：

1. `get_market_data`：取得每日**不复权收盘价**；
2. `get_gb_info_by_date`：取得每日**总股本**；
3. `get_financial_data`：取得历次财报数据及其**公告日期**。

然后计算：

[

总市值_t=不复权收盘价_ttimes 当日总股本_t

]

[

PE(TTM)_t=frac{总市值_t}{截至t日已经公告的最近一期归母净利润TTM}

]

[

PB_t=frac{总市值_t}{截至t日已经公告的最近一期归母股东权益}

]

你提供的接口足以完成。其中，专业财务数据需要提前在通达信客户端下载；K线接口一次最多返回24,000条数据。[专业财务数据文档](https://help.tdx.com.cn/quant/docs/markdown/TdxQuant.md/mindoc-1h10m001ic888.html) · [K线数据文档](https://help.tdx.com.cn/quant/docs/markdown/mindoc-1ctuhthaq5qmg/mindoc-1h10g60jt68sc.html)

---

## 推荐使用的字段

| 字段 | 含义 | 用途 |
| --- | --- | --- |
| `FN4` | 每股净资产 | 还原归母股东权益 |
| `FN238` | 总股本 | 与 `FN4` 配合计算净资产 |
| `FN308` | 近一年归母净利润，单位万元 | PE-TTM分母 |
| `FN276` | 近一年净利润，单位元 | `FN308`缺失时的备选 |
| `announce_time` | 财报公告日期 | 防止未来函数 |
| `tag_time` | 报告期截止日期 | 标记财报所属季度 |

推荐的财务分母是：

```python
归母净利润TTM = FN308 * 10000
归母股东权益 = FN4 * FN238
```

PB也可以简单写成`股价/FN4`，但如果财报披露后公司发生送转股、拆股或增发，直接使用历史`FN4`可能与当前股本不匹配。因此，更严谨的做法是：

```python
PB = 当日总市值 / (财报期末FN4 * 财报期末FN238)
```

每日总股本可以通过`get_gb_info_by_date`取得。[历史股本接口文档](https://help.tdx.com.cn/quant/docs/markdown/mindoc-1ctuhthaq5qmg/mindoc-1hc4303vsv1fk.html)

## 可直接运行的示例代码

```python
from tqcenter import tq
import pandas as pd
import numpy as np

def _single_stock_series(field_df, stock_code, name):
    """
    兼容TdxQuant可能返回的两种DataFrame方向：
    1. index=日期，columns=股票代码
    2. index=股票代码，columns=日期
    """
    if stock_code in field_df.columns:
        s = field_df[stock_code].copy()
    elif stock_code in field_df.index:
        s = field_df.loc[stock_code].copy()
    else:
        raise KeyError(f"{name}中找不到证券代码：{stock_code}")

    s.index = pd.to_datetime(s.index.astype(str))
    s = pd.to_numeric(s, errors="coerce")
    s.name = name
    return s.sort_index()

def get_historical_pe_pb(
    stock_code: str,
    start_date: str,
    end_date: str,
    conservative_announcement: bool = True,
):
    """
    计算单只A股历史PE-TTM和PB。

    参数
    ----------
    stock_code:
        如 '600519.SH'、'002299.SZ'
    start_date, end_date:
        YYYYMMDD
    conservative_announcement:
        True：财报在公告日后的下一个交易日生效，适合回测，避免盘后公告造成未来函数。
        False：公告日当日生效，适合一般历史估值展示。
    """

    # ---------------------------------------------------------
    # 1. 历史日线：估值必须使用不复权价格
    # ---------------------------------------------------------
    market_raw = tq.get_market_data(
        field_list=["Close"],
        stock_list=[stock_code],
        period="1d",
        start_time=start_date,
        end_time=end_date,
        count=-1,
        dividend_type="none",
        fill_data=True,
    )

    close = _single_stock_series(
        market_raw["Close"],
        stock_code,
        "close"
    )

    market = close.to_frame()
    market.index.name = "trade_date"
    market = market.reset_index()

    # ---------------------------------------------------------
    # 2. 每日总股本
    # ---------------------------------------------------------
    shares_raw = tq.get_gb_info_by_date(
        stock_code=stock_code,
        start_date=start_date,
        end_date=end_date,
    )

    shares = pd.DataFrame(shares_raw)

    if shares.empty:
        raise ValueError(
            "未取得股本数据，请先在通达信客户端中下载相应日K线数据。"
        )

    shares["trade_date"] = pd.to_datetime(
        shares["Date"].astype("Int64").astype(str)
    )
    shares["total_shares"] = pd.to_numeric(
        shares["Zgb"], errors="coerce"
    )

    shares = (
        shares[["trade_date", "total_shares"]]
        .drop_duplicates("trade_date", keep="last")
        .sort_values("trade_date")
    )

    market = pd.merge(
        market,
        shares,
        on="trade_date",
        how="left",
    )

    # 个别日期如股本接口缺值，使用最近有效股本
    market["total_shares"] = market["total_shares"].ffill().bfill()

    # 使用不复权价格计算总市值
    market["market_cap"] = (
        market["close"] * market["total_shares"]
    )

    # ---------------------------------------------------------
    # 3. 获取历史财务数据
    # 多向前取约两年，使开始日期附近也能匹配到上一期财报
    # ---------------------------------------------------------
    financial_start = (
        pd.to_datetime(start_date) - pd.DateOffset(years=2)
    ).strftime("%Y%m%d")

    financial_raw = tq.get_financial_data(
        stock_list=[stock_code],
        field_list=["FN4", "FN238", "FN308", "FN276"],
        start_time=financial_start,
        end_time=end_date,
        report_type="announce_time",
    )

    if stock_code not in financial_raw:
        raise ValueError(f"没有取得{stock_code}的专业财务数据。")

    financial = financial_raw[stock_code].copy()

    if financial.empty:
        raise ValueError(
            "财务数据为空，请先在通达信客户端中下载专业财务数据包。"
        )

    financial.columns = [
        str(c).upper()
        if str(c).upper().startswith("FN")
        else str(c).lower()
        for c in financial.columns
    ]

    financial["announce_time"] = pd.to_datetime(
        financial["announce_time"].astype(str),
        format="%Y%m%d",
        errors="coerce",
    )
    financial["tag_time"] = pd.to_datetime(
        financial["tag_time"].astype(str),
        format="%Y%m%d",
        errors="coerce",
    )

    for col in ["FN4", "FN238", "FN308", "FN276"]:
        if col in financial.columns:
            financial[col] = pd.to_numeric(
                financial[col], errors="coerce"
            )

    # 同一公告日如果存在多条记录，优先保留报告期较新的一条
    financial = (
        financial
        .dropna(subset=["announce_time"])
        .sort_values(["announce_time", "tag_time"])
        .drop_duplicates("announce_time", keep="last")
        .reset_index(drop=True)
    )

    # ---------------------------------------------------------
    # 4. 构造财务分母
    # ---------------------------------------------------------

    # FN308：近一年归母净利润，单位万元
    financial["net_profit_ttm"] = financial["FN308"] * 10000

    # FN308缺失时，可使用FN276作为备选。
    # 注意：FN276口径是“近一年净利润”，不一定完全等于归母口径。
    if "FN276" in financial.columns:
        financial["net_profit_ttm"] = (
            financial["net_profit_ttm"]
            .fillna(financial["FN276"])
        )

    # 财报期末归母股东权益≈每股净资产×财报期末总股本
    financial["parent_equity"] = (
        financial["FN4"] * financial["FN238"]
    )

    financial = financial[
        [
            "announce_time",
            "tag_time",
            "net_profit_ttm",
            "parent_equity",
            "FN4",
            "FN238",
        ]
    ].copy()

    # ---------------------------------------------------------
    # 5. 确定财报何时进入历史估值
    # ---------------------------------------------------------
    if conservative_announcement:
        # 将公告日映射到“公告日之后的第一个交易日”。
        # 这种处理能够避免盘后公告被错误用于公告日收盘价。
        trade_dates = market["trade_date"].sort_values().to_numpy()

        def next_trade_date(announce_date):
            pos = trade_dates.searchsorted(
                np.datetime64(announce_date),
                side="right",
            )
            if pos >= len(trade_dates):
                return pd.NaT
            return pd.Timestamp(trade_dates[pos])

        financial["effective_date"] = financial[
            "announce_time"
        ].map(next_trade_date)
    else:
        financial["effective_date"] = financial["announce_time"]

    financial = (
        financial
        .dropna(subset=["effective_date"])
        .sort_values("effective_date")
    )

    # ---------------------------------------------------------
    # 6. 按信息可获得日期向后匹配
    # ---------------------------------------------------------
    result = pd.merge_asof(
        market.sort_values("trade_date"),
        financial,
        left_on="trade_date",
        right_on="effective_date",
        direction="backward",
    )

    # ---------------------------------------------------------
    # 7. 计算PE-TTM和PB
    # ---------------------------------------------------------
    result["pe_ttm"] = (
        result["market_cap"] / result["net_profit_ttm"]
    )

    result["pb"] = (
        result["market_cap"] / result["parent_equity"]
    )

    # 净利润小于等于0时，PE通常记为空，而不是负市盈率
    result.loc[
        result["net_profit_ttm"] <= 0,
        "pe_ttm"
    ] = np.nan

    # 净资产小于等于0时，PB失去常规估值意义
    result.loc[
        result["parent_equity"] <= 0,
        "pb"
    ] = np.nan

    result["stock_code"] = stock_code

    return result[
        [
            "stock_code",
            "trade_date",
            "close",
            "total_shares",
            "market_cap",
            "announce_time",
            "tag_time",
            "net_profit_ttm",
            "parent_equity",
            "pe_ttm",
            "pb",
        ]
    ]

if __name__ == "__main__":
    tq.initialize(__file__)

    df = get_historical_pe_pb(
        stock_code="600519.SH",
        start_date="20150101",
        end_date="20260722",
        conservative_announcement=True,
    )

    print(df.tail(20))

    df.to_csv(
        "600519_historical_pe_pb.csv",
        index=False,
        encoding="utf-8-sig",
    )
```

## 为什么必须按公告日期拼接

这是计算历史PE/PB时最重要的问题。

假设某公司2025年年报的：

- 报告期：2025年12月31日；
- 公告日：2026年3月30日。

那么在2026年1月、2月的历史回测中，**不能提前使用这份年报**。否则会出现前视偏差。

因此应当使用：

```python
report_type="announce_time"
```

并通过`merge_asof(..., direction="backward")`，为每个交易日匹配当时已经公告的最近一期财务数据。`get_financial_data`返回的DataFrame同时包含`announce_time`和`tag_time`，非常适合做这种时点匹配。[接口说明](https://help.tdx.com.cn/quant/docs/markdown/TdxQuant.md/mindoc-1h10m001ic888.html)

`get_financial_data_by_date`更适合查询某个指定报告期或“最近第几期”财报，不适合直接逐日构建无未来函数的估值序列。[指定日期财务数据文档](https://help.tdx.com.cn/quant/docs/markdown/TdxQuant.md/mindoc-1h10mdt617qss.html)

## 需要特别注意的口径

1. **价格必须使用不复权价**
    
    ```python
    dividend_type="none"
    ```
    
    前复权价格会把历史价格整体调整，不能直接与当时总股本和财务数据计算历史市值。
    
2. **PE需要明确口径**
    
    上述代码计算的是：
    
    ```
    PE-TTM = 总市值 ÷ 近一年归母净利润
    ```
    
    如果需要静态PE，则应使用上一完整年度归母净利润；如果需要动态PE，则需要根据一季报、中报或三季报年化，但这种年化对周期股误差很大。
    
3. **亏损公司的PE设为空值**
    
    净利润小于或等于零时，负PE缺乏直观估值意义，通常保留为`NaN`，同时单独增加“亏损标记”。
    
4. **金融股PB口径可以进一步优化**
    
    银行、保险、券商通常更关注：
    
    - PB；
    - 归母净资产；
    - 扣除其他权益工具后的普通股净资产；
    - ROE与PB的匹配关系。
    
    如果存在优先股、永续债，仅使用`FN4 × FN238`可能与第三方数据库口径略有差异。
    
5. **与行情软件显示值可能存在小幅差异**
    
    原因通常不是代码错误，而是：
    
    - 公告日当天还是次日生效；
    - 总股本还是流通股本；
    - 归母净利润还是全部净利润；
    - 是否纳入业绩快报；
    - 是否对财务数据追溯重述；
    - 财务单位及小数精度；
    - 第三方平台对停牌日、除权日的处理不同。

总体而言，上述方案可以生成一套适合**历史估值分位、因子研究和无未来函数回测**的日频PE-TTM、PB序列。
