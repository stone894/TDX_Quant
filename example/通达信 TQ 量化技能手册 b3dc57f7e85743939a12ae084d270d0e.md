### 2.3 公式调用（指标/选股）

| 模式 | 函数 | 适用场景 |
| --- | --- | --- |
| **单只指标** | `formula_set_data_info()` → `formula_zb()` | 逐只调试 |
| **单只选股** | `formula_set_data_info()` → `formula_xg()` | 逐只调试 |
| **批量指标** | `formula_process_mul_zb()` | 全市场扫描，速度快 |
| **批量选股** | `formula_process_mul_xg()` | 全市场扫描，速度快 |

**批量指标示例（MACD金叉扫描）：**

```python
mul_zb_result = tq.formula_process_mul_zb(
    formula_name='MACD',
    formula_arg='12,26,9',
    xsflag=6,
    return_count=2,
    return_date=False,
    stock_list=all_stocks,
    stock_period='1d',
    count=100,
    dividend_type=1
)
# 判断金叉：昨日DIF<DEA 且 今日DIF>=DEA
for key in mul_zb_result:
    if key != "ErrorId":
        dif = mul_zb_result[key]['DIF']
        dea = mul_zb_result[key]['DEA']
        if len(dif) >= 2 and float(dif[-2]) < float(dea[-2]) and float(dif[-1]) >= float(dea[-1]):
            macd_stocks.append(key)
```

**批量选股示例（UPN连涨筛选）：**

## 三、Python ↔ 通达信公式双向互通

### 3.1 Python → 公式

通过 `send_bt_data()` 发送序列数据后，在通达信**公式管理器**中用 `SIGNALS_TQ(ID, TYPE)` 引用：

```
SIGNALS_TQ(ID, TYPE)
  ID:  data_list子列表中的位置索引（从1开始）
  TYPE: 0=不平滑  1=平滑填充(无数据取前值)  2=无数据为0
```

**示例公式 TQMA510：**

```
MA5:SIGNALS_TQ(1,0);
MA10:SIGNALS_TQ(2,0);
BUY_SIGNAL:=SIGNALS_TQ(3,0);
SELL_SIGNAL:=SIGNALS_TQ(4,0);
单位净值:SIGNALS_TQ(7,0),COLORWHITE;
最大回撤:SIGNALS_TQ(13,0),COLORGRAY;
DRAWICON(BUY_SIGNAL, LOW, 1);
DRAWICON(SELL_SIGNAL, HIGH, 2);
```

### 3.2 公式 → Python

通过 `formula_zb()` / `formula_xg()` / `formula_process_mul_*()` 调用客户端已有公式，获取公式计算结果用于 Python 后续逻辑。

## 四、实时预警方案

| 方案 | 机制 | 频率 | 股票上限 | 适用场景 |
| --- | --- | --- | --- | --- |
| **订阅回调** | `subscribe_hq(callback=fn)` | ~6秒 | ≤100只 | 少量标的高频监控 |

**订阅回调模板：**

## 五、回测框架

### 5.1 手写回测引擎

适合深度定制。核心流程：遍历K线 → 信号判断 → 模拟买卖（整百股、扣手续费） → 逐日计算净值/回撤/夏普/Beta。

**关键指标计算：**

- **年化收益率：** $(1 + R_{total})^{252/T} - 1$
- **最大回撤：** 净值序列 `cummax` 后计算回撤比
- **夏普比率：** $(bar{r} - r_f/252) times sqrt{252} div sigma_r$，无风险利率取2%
- **Beta：** `np.cov(策略收益, 基准收益)[0,1] / var(基准收益)`

### 5.2 vectorbt 回测

信号驱动，代码简洁，自带图形输出。

```python
import vectorbt as vbt

# 信号生成
ma = vbt.MA.run(close_df, window=5).ma
entries = close_df.vbt.crossed_above(ma).shift(1).fillna(False).astype(bool)
exits = close_df.vbt.crossed_below(ma).shift(1).fillna(False).astype(bool)

# 执行回测
portfolio = vbt.Portfolio.from_signals(
    close=close_df,
    entries=entries,
    exits=exits,
    price=open_df,           # 次日开盘成交
    init_cash=100000,
    fees=0.0003,             # 手续费0.03%
    freq='D',
    size_granularity=100     # A股最小100股
)

portfolio.stats()                      # 统计报告
portfolio.trades.records_readable      # 交易记录
portfolio[stock].plot().show()         # 交互式图形
```

<aside>
⚠️

`vbt.Portfolio.from_signals` 不支持分红送股等权益变动，仅适合快速验证。

</aside>

## 六、常用技术指标计算模板

```python
import pandas as pd

def ema(s, w): return s.ewm(span=w, adjust=False).mean()
def sma(s, w): return s.rolling(w).mean()
def llv(s, w): return s.rolling(w).min()
def hhv(s, w): return s.rolling(w).max()
def ref(s, n): return s.shift(n)

def cross_above(fast, slow):
    """金叉信号：快线上穿慢线"""
    return ((fast > slow) & (ref(fast, 1) <= ref(slow, 1))).astype(int)
```

## 七、量化交易方法论（五步法）

1. **投资想法** → 金叉买入死叉卖出等初步思路
2. **明确策略** → 品种（Security）、条件（Condition）、数量（Quantity）
3. **编码实现** → Python + TQ API 转化为可执行程序
4. **回测验证** → 历史数据回测 + 模拟交易（虚拟资金 + 真实行情）
5. **实盘优化** → 真金白银交易 + 持续监控改进

**策略可执行性判断标准：** 不同的人根据同一策略描述，在相同情形下能做出相同的交易操作。

## 八、代码格式规范备忘

- 股票代码格式：`6位数 + .SH/.SZ/.JJ`（如 `688318.SH`）
- 时间格式：`YYYYMMDD` 或 `YYYYMMDDHHMMSS`
- K线周期：`1d` / `1w` / `1m` / `5m` / `15m` / `30m` / `60m`
- 复权类型：`none`（不复权）/ `front`（前复权）/ `back`（后复权）
- `send_warn` 的 `reason_list` 每项最长25个汉字（50个英文字符）
