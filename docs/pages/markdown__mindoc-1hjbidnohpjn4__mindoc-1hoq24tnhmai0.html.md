### # 获取分时统计数据get_exmin_data

#### # 获取单只证券当日分时资金流向统计，按分钟返回特大/大/中/小四档的买入、卖出、主买、主卖金额，数值为开盘至今的累计值

```
get_exmin_data(
stock_code: str,
type: int = 0
) -> DataFrame
```

#### # 输入参数

| 参数 | 是否必选 | 参数类型 | 参数说明 |
|---|---|---|---|
| stock_code | Y | str | 单只证券代码，必须带市场后缀，例如 600000.SH |
| type | N | int | 统计口径，0 金额（元）、1 成交量（手）、2 成交笔数（笔），默认 0 |

#### # 返回数据

| 数据字段 | 默认返回 | 数据类型 | 数据说明 |
|---|---|---|---|
| 特大买入 | Y | float | 特大单买入 |
| 特大卖出 | Y | float | 特大单卖出 |
| 特大主买 | Y | float | 特大单主动买入 |
| 特大主卖 | Y | float | 特大单主动卖出 |
| 大买入 | Y | float | 大单买入 |
| 大卖出 | Y | float | 大单卖出 |
| 大主买 | Y | float | 大单主动买入 |
| 大主卖 | Y | float | 大单主动卖出 |
| 中买入 | Y | float | 中单买入 |
| 中卖出 | Y | float | 中单卖出 |
| 中主买 | Y | float | 中单主动买入 |
| 中主卖 | Y | float | 中单主动卖出 |
| 小买入 | Y | float | 小单买入 |
| 小卖出 | Y | float | 小单卖出 |
| 小主买 | Y | float | 小单主动买入 |
| 小主卖 | Y | float | 小单主动卖出 |

行索引为时间点，HHMM 字符串，索引名 Time，不是列

每一行的数值是

开盘至今的累计值，不是该分钟的增量；取当日统计量用最后一行，逐行求和会把结果放大上百倍主买、主卖是买入、卖出中的主动成交部分，属于子集，统计总量时只用买入与卖出共 8 列


#### # 接口使用

获取 600000.SH 当日的分时金额统计。

```
from tdxaidata import tqs
exmin = tqs.get_exmin_data(
stock_code="600000.SH",
type=0,
)
print(exmin)
```
