### # 提供3个Skills包供各智能体平台安装

通达信TQ-Local （V1.3.2）

https://www.tdx.com.cn/products/autoup/skills/tdx-tq-local.zip (opens new window)

通达信AiData （V1.3.2）

https://www.tdx.com.cn/products/autoup/skills/tdx-aidata.zip (opens new window)

通达信Lambda （V1.2.2）

https://www.tdx.com.cn/products/autoup/skills/tdx-lambda.zip (opens new window)

将以上zip解压后，在WorkBuddy,TRAE Work,CodeX或TdxClaw等AI平台中安装。

### # 通达信TQ-Local介绍

AI平台中直接调取本地TQ数据，也可以编写Python代码。需要开启通达信支持TQ策略的客户端。

### # 通达信AiData介绍

AI会根据此Skill用Python函数从通达信后台取数据(tqs模式,不需要开启通达信客户端)

### # 通达信Lambda介绍

AI平台中编写Python算法代码，发到通达信客户端中的Lamba策略系统中进行回测或执行。
