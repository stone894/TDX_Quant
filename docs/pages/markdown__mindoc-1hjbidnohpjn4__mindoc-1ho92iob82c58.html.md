### # 获取个股综合信息get_misc_data

按单只证券返回行业地位、主营业务、所属板块、最新分红、涨停和异动原因、质押与解禁等已格式化的信息

范围：只支持沪深京品种

```
get_misc_data(
stock_code: str,
field_list: list[str] = None
) -> dict
```

#### # 输入参数

| 参数 | 是否必选 | 参数类型 | 参数说明 |
|---|---|---|---|
| stock_code | Y | str | 证券代码，必须带市场后缀，如 000001.SZ、600000.SH |
| field_list | N | list[str] | 按中文栏目名筛选，如 ["所属板块", "最新分红"]；留空返回全部栏目 |

#### # 返回数据

| 数据字段 | 默认返回 | 数据类型 | 数据说明 |
|---|---|---|---|
| 行业地位 | Y | str | 公司在行业中的定位描述 |
| 行业地域 | Y | str | 行业与经营地域类别，如 全国性银行 |
| 地区 | Y | str | 公司注册地，如 广东-深圳市 |
| 主营业务 | Y | str | 主营业务范围说明 |
| 所属板块 | Y | str | 所属概念与风格板块，逗号分隔 |
| 所属主题 | Y | str | 所属主题标签，逗号分隔 |
| 新增概念 | Y | str | 最近最加的概念和主题 |
| 最新涨停 | Y | str | 涨停原因简述 |
| 最新跌停 | Y | str | 跌停原因简述 |
| 异动原因 | Y | str | 涨超10%或跌超10%的原因 |
| 最新分红 | Y | str | 最近一次分红方案，如 10派2.49元(含税) |
| 最近解禁 | Y | str | 近期解禁情况，如 未来三个月无 |
| 解禁原因 | Y | str | 该解禁的原因 |
| 解禁数量 | Y | str | 该解禁的数量 |
| 总质押数 | Y | str | 股权质押总股数，如 2438.48万股 |
| 占总股本比 | Y | str | 质押股数占总股本比例，如 0.13% |
| 减持计划 | Y | str | 减持计划，如 无减持计划 |
| 最新计划 | Y | str | 减持的具体 |
| 合计减持 | Y | str | 合计减持的数量 |
| 北向成交 | Y | str | 北向成交的情况 |
| 配股提示 | Y | str | 配股相关 |
| 配股登记 | Y | str | 配股相关 |
| 配股缴款 | Y | str | 配股相关 |
| 复牌日期 | Y | str | 配股相关 |
| 配股上市 | Y | str | 配股相关 |
| 最新要约 | Y | str | 要约相关 |
| 收购数量 | Y | str | 要约相关 |
| 占总股本比 | Y | str | 要约相关 |
| 沪深港通 | Y | str | 沪深港通 |
| 指数调整 | Y | str | 调入或调出指数 |
| 做市信息 | Y | str | 做市机构 |
| 机构调研 | Y | str | 机构调研信息 |
| 互动问答 | Y | str | 互动问答信息 |
| 业绩预告 | Y | str | 最近业绩预告 |
| 财报披露 | Y | str | 最近财报的披露时间安排 |
| 股东大会 | Y | str | 最近股东会召开情况 |
| 停牌复牌 | Y | str | 停牌或复牌 |
| 大宗交易 | Y | str | 最近的大宗交易 |
| 龙虎榜单 | Y | str | 最近的上榜信息 |
| 融资买入 | Y | str | 最近的融资买入信息 |
| 最新公告 | Y | str | 最近披露的公告 |

栏目集合与顺序由个股自身资料决定，不同证券可能不同；上表为 000001.SZ 实测返回的 12 个栏目。内容均为已格式化的中文文本，如 2438.48万股、0.13%、10派2.49元(含税)，不做数值转换。


证券无综合信息资料时会打印

`[错误] sim file not found`

并返回`{}`

（如 600000.SH）；`stock_code`

未带市场后缀时打印`[错误] Invalid stock code`

并返回`{}`

；`stock_code`

为空时打印`[错误] stock_code 不能为空`

并返回`{}`

。

#### # 接口使用

取平安银行（000001.SZ）的全部综合信息栏目。

```
from tdxaidata import tqs
data = get_misc_data(
stock_code="000001.SZ",
)
print(data)
```
